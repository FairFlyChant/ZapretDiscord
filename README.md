> [!WARNING]

> ### Реакция антивирусов
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик, поэтому он нужен для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и помещается в карантин. Название обнаружения обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно умеете настраивать исключения, предпочтительно добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика DNS, отличный от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — провайдер Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется именно этот вариант.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если отключить его, Secure DNS на компьютере может работать неправильно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/FairFlyChant/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот шаг не требуется.

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Чтобы определить рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Для автоматического запуска перейдите в **`service.bat`** -> `Install Service` и выберите подходящую стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб.
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** — выбор режима обхода для сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret открывается, а с ним — нет.  
  В скобках отображается состояние:
    - `none` — ни один IP не проверяется;
    - `loaded` — IP проверяются на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений.
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход); его можно увидеть на панели задач.  
Если этого не случилось, обратитесь к [#522](https://github.com/FairFlyChant/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает Telegram (веб-версия)

В **`service.bat`** выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированное в конец `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантируется. Если это не помогло, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FairFlyChant/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Стратегия способна работать некоторое время, а затем перестать обходить блокировку после обнаружения.
> Здесь собрано много вариантов стратегий. Если ни один не подходит, создайте новую на основе одной из имеющихся, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок.
- Убедитесь, что адрес нужного ресурса внесён в списки доменов или IP.
- Попробуйте другие стратегии, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/FairFlyChant/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки, а в конце ответьте Y.
- Удалите папку zapret.
- Загрузите последнюю версию со [страницы релизов](https://github.com/FairFlyChant/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить» и «ОК».
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если интернет не работает, закройте программу через значок замка на панели задач и выберите другую стратегию.
- Найдя рабочий вариант, включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Не работает игра или приложение при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтр может повлиять на ресурсы, которые вы не собирались обходить.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите её, подставив полученное имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/FairFlyChant/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord — помогла ли очистка кэша?
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если Discord не работает и в браузере, снова проверьте все стратегии. YouTube и Discord могут требовать разные варианты.
- См. также [#252](https://github.com/FairFlyChant/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/FairFlyChant/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`;
- если результата нет, дополнительно включить `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если это тоже не помогло, создайте обсуждение в разделе [Discussions](https://github.com/FairFlyChant/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/FairFlyChant/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Нужные адреса можно добавить в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
